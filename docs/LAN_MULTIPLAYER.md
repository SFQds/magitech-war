# 局域网联机对战 — 使用说明

魔导工业革命支持**局域网 1v1 人 vs 人**对战。采用**状态同步（权威主机）**架构：
主机运行完整模拟并定期广播快照，客户端只发命令、收快照、渲染。

## 运行前提

- 开发环境启动：`npx vite --port 3000`
- 联机需要同一局域网内两台设备，都访问主机的开发服务器
- 浏览器原生 WebSocket 即可，无需额外安装

## 架构

```
┌─────────────────────────────────────────────┐
│  Vite dev server (Node)                     │
│  └─ lanRelayPlugin: WebSocket 中继 (/lan)   │
│     2 槽位: host + client, 双向转发消息      │
└─────────────────────────────────────────────┘
        ▲ ws://<主机IP>:3000/lan    ▲
        │                          │
   ┌────┴────┐                ┌────┴────┐
   │  主机    │   lobby_state  │  客户端  │
   │ (owner0) │◄──────────────►│ (owner1)│
   │ 跑模拟    │   cmd / snapshot│ 只渲染   │
   └─────────┘                └─────────┘
```

- **主机**：连本机中继（`ws://localhost:3000/lan`），身份 `role=host`，玩家 0。
  运行完整 13 步模拟，每 100ms 序列化游戏状态广播给客户端。
- **客户端**：连主机中继（`ws://<主机IP>:3000/lan`），身份 `role=client`，玩家 1。
  不跑模拟，右键/HUD 操作构造命令发给主机；收到快照后 `deserialize` 重建状态渲染。

## 对战流程

1. 主机启动 `npx vite --port 3000`，浏览器打开进入 main 菜单
2. 主机点 **「🌐 局域网联机」** → 进入大厅（主机模式）
3. 客户端在同一局域网另一台设备，浏览器打开 **`http://<主机IP>:3000`**，
   点 **「🌐 局域网联机」** → 大厅（客户端模式）→ 输入主机 IP → 点 **「🔗 连接」**
4. 双方各自**选阵营 + 行会**，点 **「✓ 准备」**
5. 双方都准备后，主机点 **「▶ 开始游戏」** → 双方自动进入 GameScene 对战
6. 主机操作玩家 0（主机视角），客户端操作玩家 1（客户端视角）

## 联机模式下的操作

- **选择单位**：左键单击 / 框选（客户端只选中自己 owner 1 的单位）
- **移动/攻击/采集**：右键智能命令（客户端经网络发给主机）
- **训练/研究/建造/超武**：HUD 按钮（客户端经网络发给主机）
- 快捷键：F2 全选作战单位 等，单机方式相同

## 网络消息协议

定义于 `src/net/NetMessages.ts`，全部为 JSON 可序列化的纯数据：

| 类型 | 方向 | 说明 |
|------|------|------|
| `hello` | 双方→中继 | 声明身份 role (host/client) |
| `client_joined` | 中继→主机 | 客户端连入通知 |
| `lobby_state` / `lobby_update` | 双方 | 大厅选阵营/行会/准备同步 |
| `start` | 主机→客户端 | 开局初始化 GameInitData |
| `cmd` | 客户端→主机 | 客户端命令 |
| `snapshot` | 主机→客户端 | 游戏状态快照 (SaveData) |
| `gameover` | 主机→客户端 | 结算通知 |
| `peer_disconnect` | 中继→对方 | 对端断开 |

## 已知限制（MVP）

- **客户端输入延迟**：~100ms（等主机快照），无本地预测
- **客户端建造/快捷键仍需命令化**：客户端直接右键移动/攻击/采集已命令化；
  而 HUD 建造入口（`enterBuildMode`）与 S/H/Q/R 快捷键仍直接改本地状态、未走网络命令，
  客户端联机对这些操作无效。需在后续迭代补齐（对齐右键的命令化分支）。
- **断线即结束**：无自动重连（中继已支持同槽位重连接管，客户端 `NetClient` 有基础重连）
- **固定地图**：联机固定 `map_valley`
- **生产部署**：中继仅挂在 Vite dev server；正式生产需独立 Node 入口（后续迭代）
